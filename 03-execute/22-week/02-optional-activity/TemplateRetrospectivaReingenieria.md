# Regla de evaluacion

Una propuesta solo se considera valida cuando cumple estas condiciones:

- [ ] El problema existe realmente.
- [ ] El problema afecta a un usuario y a un flujo concreto.
- [ ] Existe evidencia dentro del mockup o del proceso analizado.
- [ ] La propuesta resuelve directamente el problema.
- [ ] La funcionalidad propuesta es minima y viable.
- [ ] La interfaz facilita el nuevo flujo.
- [ ] No incorpora sobreingenieria innecesaria.
- [ ] La relacion con SIGA esta fundamentada.
- [ ] El resultado esperado puede comprobarse.

# Estructura resumida

> **Usuario y flujo → Problema real → Evidencia → Propuesta → Justificacion → Funcionalidad minima → UX/UI → No sobreingenieria → SIGA → Resultado esperado**
