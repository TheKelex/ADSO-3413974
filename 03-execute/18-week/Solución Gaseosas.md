### Entendimiento Problema

Los empleados no recibieron capacitacion previa, su entendimiento de negocio es la compra y venta de productos Condor (Gaseosas).

1. Falta de stock en productos especificos.
2. Venta de productos recientes que hace que los productos antiguos se venzan.

**Los problemas no requieren una solucion especifa de software**

-----------------------------------------------------------------------------------------------------

### Solucion Problema No. 1

Para resolver el problema de la falta de stock en productos especificos se realizaria este paso a paso:

1. Tener organizado el almacen de los productos.
2. Realizar un analisis de venta los productos (de manera cuantitativa) a los que se les acaba el stock.
3. Revisar los resultados obtenidos para llegar a un consenso.
4. Obtener un resultado cuantitativo de cuantos productos se deben comprar para evitar la falta de stock.

-----------------------------------------------------------------------------------------------------

### Solucion Problema No. 2

Para resolver el problema de el vencimiento en antiguos productos se realizo el siguiente analisis:

La empresa al no brindarle capacitacion a los empleados, no se les dan indicaciones acerca de los sistemas que se usan, por consiguiente se haria el siguiente paso a paso:

1. Si no se cuenta con un sistema de colas para el inventario se implementa.
2. Se realizan capacitaciones para que los empleados organicen el inventario mediante este sistema.

**Sistema de colas:**

Al momento de recibir productos nuevos estos se dejan en cola hasta vender los antiguos productos.
