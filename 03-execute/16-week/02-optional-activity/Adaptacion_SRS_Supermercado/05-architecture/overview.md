## Vista general

La solución propuesta se compone de una aplicación web, una aplicación móvil Android, una API REST y una base de datos relacional.

## Componentes

- **Frontend web:** acceso desde navegadores modernos.
- **Frontend móvil:** acceso Android para operación en campo o en tienda.
- **Backend/API REST:** lógica de negocio, autenticación y reglas.
- **Base de datos:** almacenamiento de ventas, inventario, proveedores, fiados y reportes.

## Decisiones base

- Comunicación por HTTP/HTTPS.
- Persistencia en base de datos relacional.
- Actualización en tiempo real o con demora mínima.
