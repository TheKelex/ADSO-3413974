# ADR-001 — API REST como canal principal

> Estado: Aprobado | Última actualización: 2026-07-03
> Autor: Kevin Santiago Saavedra Chantris | Equipo: Kevin Santiago Saavedra Chantris / SENA ADSO 3413974

## Contexto

El sistema necesita comunicación entre web, móvil y base de datos.

## Decisión

Usar una API REST como capa central de integración.

## Consecuencias

- Facilidad de mantenimiento.
- Comunicación multiplataforma.
- Estandarización de contratos.
