# ADR-002 — Base de datos relacional

> Estado: Aprobado | Última actualización: 2026-07-03
> Autor: Kevin Santiago Saavedra Chantris | Equipo: Kevin Santiago Saavedra Chantris / SENA ADSO 3413974

## Contexto

Se requiere integridad de datos para ventas, inventario y fiados.

## Decisión

Usar base de datos relacional.

## Consecuencias

- Mejor control de relaciones.
- Consultas consistentes.
- Más trazabilidad de transacciones.
