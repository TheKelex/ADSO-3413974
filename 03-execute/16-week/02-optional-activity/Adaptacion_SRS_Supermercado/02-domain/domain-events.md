## Eventos de dominio

- **VentaRegistrada:** se crea una venta y se descuentan existencias.
- **InventarioActualizado:** cambia el stock después de ventas o ajustes.
- **StockBajoDetectado:** un producto llega a nivel mínimo.
- **ProductoAgotadoDetectado:** no queda inventario disponible.
- **ProveedorRegistrado:** se crea o actualiza un proveedor.
- **PedidoRegistrado:** se almacena una solicitud a proveedor.
- **FiadoRegistrado:** se crea una deuda asociada a un cliente.
- **AbonoAplicado:** se registra un pago parcial de un fiado.
- **ReporteGenerado:** se prepara un informe diario o mensual.
