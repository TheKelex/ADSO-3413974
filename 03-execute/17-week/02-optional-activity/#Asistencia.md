#Asistencia

Planteamiento general: Se requiere un sistema que permita registrar la asistencia de manera mas eficiente (sin contar el uso de Sofia Plus)

##Requisitos

###Requisitos Funcionales

RF-01:

	Permitir el registro de asistencia mediante el QR generado para el carnet personal de cada aprendiz

	####PreRequisito

		- El sistema debe tener acceso a la cámara
		- El aprendiz debe tener el carnet

RF-02:

	Al momento de registrar la asistencia se pedirá una fotografía del ambiente vista de frente

RF-03:

	El sistema debe permitir ingresar las listas directamente desde el Sofia Plus separadas por Enters para que el sistema las pueda detectar

###Requisitos No Funcional

RNF-01:

	Al momento de registrar la fotografía se guardan los metadatos para comparar que las fotografías sean distintas entre si

RNF-02:

	Después de un mes se borran las fotografías anteriores para liberar almacenamiento
