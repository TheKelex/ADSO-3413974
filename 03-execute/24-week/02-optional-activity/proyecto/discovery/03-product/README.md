# 03 — Definición del Producto (Product Definition)

> **¿Qué es esto?** La respuesta a "¿qué vamos a construir?". No es el "cómo" (eso corresponde a la arquitectura). Aquí se define el problema validado y la visión del producto.

## Por qué existe esta sección

Sin una definición clara del producto:
- El equipo construye funcionalidades que nadie solicitó.
- El alcance crece sin control (crecimiento descontrolado del alcance).
- No hay forma de saber si el proyecto fue exitoso.

Esta sección es el contrato entre el equipo de desarrollo y los interesados (stakeholders) sobre **qué se construirá y por qué**.

## Preguntas que esta sección debe responder

- **¿Qué problema exacto estamos resolviendo?** Ineficiencia operativa, pérdida de trazabilidad de datos históricos, errores financieros en la gestión de garantías y mantenimiento puramente reactivo en el taller.
- **¿Cómo se ve el éxito del producto?** Procesos de soporte optimizados en tiempo, control absoluto sobre las garantías de repuestos/mano de obra e historial predictivo unificado por automotor.
